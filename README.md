# Shadow Tower

Binary-matching decompilation of Shadow Tower for the PlayStation, North American
release `SLUS-00863`.

Original project contributions are dedicated to the public domain under
[CC0 1.0 Universal](LICENSE), to the extent of the contributors' rights.
This does not grant rights to FromSoftware's game or Sony/Psy-Q material.
No game data is included: supply your own disc image. The Nix environment
downloads the historical Psy-Q 3.0 SDK separately; see
[the toolchain documentation](docs/toolchain.md).

The disc carries seven linked programs: the boot loader (`SLUS_008.63`, called `PSX.EXE` here; the disc also holds an identical `PSX.EXE`) and six programs that it or each other load: `STR.EXE`, `ST.EXE`, `TITLE.EXE`, `OPTXT.EXE`, `VS.EXE` and `END.EXE`. All but `TITLE.EXE` (`0x80012000`) load at `0x80011000`. Which program loads which is not yet mapped.

| Image | Disc file | Load address | Load size |
| :---- | :-------- | -----------: | --------: |
| `PSX.EXE` | `SLUS_008.63` | `0x80010000` | `0x800` |
| `STR.EXE` | `STR.EXE` | `0x80011000` | `0x22000` |
| `ST.EXE` | `ST.EXE` | `0x80011000` | `0x77800` |
| `TITLE.EXE` | `TITLE.EXE` | `0x80012000` | `0x17000` |
| `OPTXT.EXE` | `OPTXT.EXE` | `0x80011000` | `0xe800` |
| `VS.EXE` | `VS.EXE` | `0x80011000` | `0x52800` |
| `END.EXE` | `END.EXE` | `0x80011000` | `0x1f000` |

## Getting started

```sh
nix develop
kf extract --disc /path/to/ShadowTower.cue   # checks the disc hash, writes retail/
kf init --retail-dir retail
kf build
kf status
```

`config/images.toml` records the disc and executable hashes. `kf extract`
refuses any other dump.

The tooling and matching workflow come from the King's Field II
(`SLPS-00069`) project, which builds on the King's Field (`SLPS-00017`)
project. Its compiler probes, linker library order and SDK attribution were
proven for King's Field II, so here they are starting hypotheses. See
[AGENTS.md](AGENTS.md) for the reconstruction rules.
