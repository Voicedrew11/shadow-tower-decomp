# Reconstructed sources

One directory per image key (`psx/`, `str/`, `st/`, `title/`, `optxt/`, `vs/`, `end/`, and `fdat_002/` ... `fdat_472/` for
the FDAT overlays), plus `lib/` for sources linked into several images. Enrol each source in `config/units.toml`; see
[the build system](../docs/build-system.md).
